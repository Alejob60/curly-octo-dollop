# 🏛️ Manual de Operación: Sistema Orbital Prime GovDocs

## 1. Visión General
**Orbital Prime** es un motor de gestión documental inteligente de grado gubernamental, diseñado específicamente para la Alcaldía de Santiago de Cali. El sistema automatiza el ciclo de vida completo de una PQRSD (Petición, Queja, Reclamo, Sugerencia o Denuncia), garantizando seguridad jurídica y soberanía de datos.

## 2. Pilares de Seguridad
### 🛡️ Privacy Shield (Habeas Data)
El sistema utiliza una arquitectura de **Tokenización y Rehidratación**. La Inteligencia Artificial procesa la información de forma anonimizada (usando tokens como `[ID_01]`), mientras que los datos reales del ciudadano nunca salen de la bóveda segura de PostgreSQL.

### 🏛️ Búnker Digital inmutable
Cada radicación genera un contenedor inalterable en la nube con una política de retención de **20 años**, cumpliendo con los estándares de archivo nacional.

## 3. Flujo de Operación Ciudadana

### Paso 1: Ingesta Inteligente
El ciudadano ingresa su solicitud a través del **Chat Inteligente** o el **Formulario Tradicional**. El sistema analiza los hechos en tiempo real.

### Paso 2: Validación de Identidad y Contacto
Mediante tarjetas interactivas, el ciudadano confirma sus datos. El sistema consulta automáticamente la base de datos para pre-llenar información si el ciudadano ya ha interactuado previamente con la entidad.

### Paso 3: Acervo Probatorio
Se permite la carga de documentos de soporte (PDF/JPG) que quedan vinculados permanentemente al radicado.

## 4. Artefactos Generados (La Trilogía Documental)
Al finalizar el proceso, el sistema entrega instantáneamente tres documentos oficiales:
1.  **Memorial de PQRSD:** El documento formal del ciudadano con fundamento legal.
2.  **Oficio de Traslado:** Instrucción técnica para la dependencia competente detectada por el sistema.
3.  **Borrador de Proyección:** Una base jurídica para facilitar la respuesta del funcionario.

Todos los documentos cuentan con un **Sello QR de Validación** para verificar su autenticidad en tiempo real.

## 5. Guía de Inicio Rápido para Funcionarios
1.  **Dashboard:** Acceda al panel de gobernanza para monitorear el flujo de radicados por dependencia.
2.  **Tracking:** Localice cualquier radicado mediante su código único o documento del ciudadano.
3.  **Auditoría:** Revise los logs de e-status para verificar la trazabilidad forense de cada trámite.
